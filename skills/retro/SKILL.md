# Retro

1. Geh den Chat durch: Was ist neu, was hat sich geändert, was wurde entschieden, wo gab es Reibung oder eine Korrektur von mir?
2. Prüf `system/learnings.md`: Gibt es ein wiederkehrendes Muster, das eine gezielte Anpassung im System lohnt (z. B. in `SOUL.md`, `AGENTS.md`, einer Vorlage in `system/templates/`, einem neuen Ordner oder einem eigenen Skill)?
3. Ordne jeden Punkt dem richtigen Ort zu: `USER.md`, `SOUL.md`, Person, Organisation, Projekt (Current Truth und Timeline), `decisions/`, `system/learnings.md`, Skill oder Regel. Nichts doppelt anlegen.
4. Zeig mir eine kurze, klare Liste: was du wohin schreibst und welche System-Verbesserung du aus den Learnings ableitest.
5. Nach meinem Okay setzt du alles um. Jede Korrektur von mir landet in `system/learnings.md` inklusive dem, was sich dadurch konkret im System geändert hat.
6. Prüf zum Schluss, ob `INDEX.md` noch stimmt.
