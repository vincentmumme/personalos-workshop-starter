# INDEX – die Karte

| Ort | Was liegt dort |
|---|---|
| `AGENTS.md` | Einstieg und Grundregeln für jeden Agenten |
| `USER.md` | Wer ich bin, woran und wie ich arbeite |
| `SOUL.md` | Wie der Agent mit mir arbeitet |
| `people/` | Menschen: eine Datei pro Person |
| `companies/` | Organisationen: Kunden, Arbeitgeber, Partner |
| `projects/` | Projekte mit Anfang und Abschluss: Ziel, Stand, nächste Schritte |
| `decisions/` | Wichtige Entscheidungen: was und warum |
| `inbox/` | Optionaler Parkplatz für unsortierten Input |
| `skills/` | Meine eigenen Skills (entstehen aus wiederkehrender Arbeit) |
| `system/rules.md` | Die Grundregeln ausführlich mit Beispielen |
| `system/templates/` | Vorlagen für Person, Organisation, Projekt, Entscheidung |
| `system/tools.md` | Zentrale Tool-Anbindung über die Composio CLI |
| `system/learnings.md` | Was das System gelernt hat und was sich dadurch geändert hat |

Neue Bereiche trägt der Agent hier ein, sobald sie entstehen.
